What this example proves

The rule this design follows

Above the type sections everything is a control — the 72 pt label-left / value-right rhythm. Inside a type section everything is content — the 44 pt floor the Lists, Prep and Ingredients sections already use. A reservation is something you typed, not something you set.

Identity goes in the header line, not a section. Detail should never say less than the row that opened it.

Editing is section-level, not row-level. Each section header carries one Edit; the rows stay content, so a tap on a link row still opens the link. One sheet per type carries the whole details object, because PATCH replaces it wholesale.

An empty group is a named chip in Add to this plan — the same door the Edit action opens.
