# Triage labels

Use these one-to-one GitHub label meanings when triaging an authorized remote issue:

| Workflow state | GitHub label |
| --- | --- |
| Awaiting classification | `needs-triage` |
| Missing reporter or stakeholder information | `needs-info` |
| Ready for autonomous implementation | `ready-for-agent` |
| Requires a human decision or external action | `ready-for-human` |
| Intentionally declined | `wontfix` |

Preserve an existing equivalent label if the remote already defines one; do not create a
duplicate spelling without explicit authorization.
