# Issue tracker convention

The repository's `origin` is `https://github.com/malikujjwal/ordinarydays.git`, so GitHub Issues
is the default remote issue tracker.

- Use an existing GitHub issue when the task supplies one.
- Do not infer or create a remote issue when a local specification or direct request is the
  supplied source of truth.
- Local implementation specifications live under `docs/03-implementation/` and may be cited
  directly by review, planning, and ticket workflows.
- Remote issue creation, mutation, or labeling requires explicit authorization.
